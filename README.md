# ממיר ל-PDF – PWA לאייפד + שרת LibreOffice

## 1. פריסה (פעם אחת)
הפרויקט כולל Dockerfile. הדרך הקלה – Render.com:
1. העלה את התיקייה ל-GitHub (repo פרטי).
2. ב-Render: New → Web Service → בחר את ה-repo → Runtime: **Docker**.
3. (מומלץ) Environment: הוסף `TOKEN` עם סיסמה כלשהי, כדי שאף אחד אחר לא ישתמש בשרת.
4. אחרי הפריסה תקבל כתובת כמו `https://pdf-converter-xxxx.onrender.com`.

אפשר גם Fly.io / Railway / VPS: `docker build -t conv . && docker run -p 3000:3000 -e TOKEN=סיסמה conv`

## 2. התקנת האפליקציה באייפד
Safari → פתח את הכתובת → שתף → "הוסף למסך הבית". בהגדרות באפליקציה הזן את ה-TOKEN.
בחירת קובץ ממירה אוטומטית; אפשר להוריד או "שמור ל'קבצים'".

## 3. "פתח באמצעות" – קיצור דרך (Shortcuts)
iOS לא מאפשר ל-PWA להופיע ב"פתח באמצעות", אבל קיצור דרך כן מופיע בתפריט "שתף":
1. אפליקציית **קיצורי דרך** → + → שם: "המר ל-PDF".
2. פרטי הקיצור (i): הפעל **הצג בגיליון שיתוף**, סוגי קבצים: **מסמכים / קבצים**.
3. פעולות:
   - **קבל תוכן מכתובת URL**: הכתובת `https://הכתובת-שלך/convert?name=` ואחריה המשתנה **שם** של קלט הקיצור.
     שיטה: **POST** · גוף הבקשה: **קובץ** · קובץ: קלט הקיצור · כותרת `x-token` = הסיסמה שלך (אם הגדרת).
   - **שמור קובץ** (או "הצג תצוגה מקדימה" / "שתף") על התוצאה.
4. עכשיו: בקבצים → לחיצה ארוכה על docx/pptx → שתף → "המר ל-PDF".

## בדיקה מקומית
`npm install && npm start` (דורש LibreOffice מותקן) → http://localhost:3000
